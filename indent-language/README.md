# Indent Language Extension

Local VS Code language support for `.ind` files.

Includes:

- Syntax highlighting
- Language configuration
- Snippets
- Command Palette action: `Indent: New Project`
- Command Palette action: `Indent: Configure Run/Debug For Workspace`
- Command Palette action: `Indent: Run Current File`
- Command Palette action: `Indent: Debug Current File`
